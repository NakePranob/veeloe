# controller-idle-work Specification

## Purpose
หน้า Idle Work ของ Agent ใน Controller: งานแต่ละชิ้นกับสถานะ ค่าของลิสต์ และงานที่ Agent เสนอ (ADR 0056)

## Requirements

### Requirement: หน้า Idle Work ในหน้า Agent
หน้า Agent SHALL มีแถว Idle Work ที่เปิดหน้า Idle Work ของ Agent นั้น หน้า Idle Work SHALL แสดงงานทุกชิ้นตามลำดับ แต่ละชิ้นเป็นแถวแบบแถวของหน้า Schedule ที่มีข้อความ จุดสีตามสถานะ (`pending`, `working`, `done`, `timedOut`, `needsApproval`) และเวลาที่รันล่าสุด กดแถว SHALL เปิด sheet ของชิ้นนั้น และลากที่จุดด้านขวาของแถว SHALL ย้ายชิ้นนั้นไปตำแหน่งใหม่ซึ่งเซ็นลิสต์ใหม่เมื่อปล่อย (VoiceOver ย้ายทีละตำแหน่งด้วยการปัดขึ้นลง) ระหว่างลากหน้า SHALL ไม่เลื่อน ใต้รายการ หน้า SHALL มีสวิตช์พักหรือทำต่อ และตัวเลือกเวลาเงียบก่อนตื่นกับเพดาน Budget ของงานพื้นหลัง ซึ่งแต่ละอันเซ็นลิสต์ใหม่ทันทีที่เลือก หน้า SHALL มีสถานะกำลังโหลด ว่าง error และ Machine ออฟไลน์ คำทั้งหมด SHALL มีทั้งไทยและอังกฤษ

#### Scenario: ยังไม่มีลิสต์
- **WHEN** Agent ยังไม่มีลิสต์ `idle` และไม่มีร่าง
- **THEN** หน้าแสดงสถานะว่างพร้อมปุ่มเพิ่มงาน

#### Scenario: ชิ้นที่ต้องการ Approval
- **WHEN** ชิ้นหนึ่งมีสถานะ `needsApproval`
- **THEN** แถวของชิ้นนั้นมีจุดสีส้ม และ sheet ของชิ้นนั้นเปิด Task ล่าสุดได้และมีปุ่มทำชิ้นนี้ใหม่

### Requirement: sheet ของแต่ละชิ้น
ปุ่มเพิ่มและแถวของชิ้น SHALL เปิด sheet ของชิ้นนั้น ซึ่งแก้ข้อความ เปิด Task ของรอบล่าสุด และเอาชิ้นนั้นออกได้ ชิ้นที่มีสถานะ `timedOut` หรือ `needsApproval` SHALL มีปุ่มทำชิ้นนี้ใหม่ ซึ่งเซ็นลิสต์โดยให้ชิ้นนั้นมี `id` ใหม่ที่ตำแหน่งเดิม จึงกลับไปเป็น `pending` การบันทึกทุกครั้ง SHALL เซ็นทั้งลิสต์ด้วย `trigger.set` หลังยืนยันตัว (ADR 0012) จากลิสต์และ scope ตามที่ Machine ถืออยู่ตอนกดบันทึก การเอาชิ้นสุดท้ายออก SHALL ลบทั้งลิสต์ด้วย `trigger.delete`

#### Scenario: เพิ่มงาน
- **WHEN** ลิสต์มีหนึ่งชิ้น แล้ว Member เพิ่มงานใหม่และกดบันทึก
- **THEN** Controller ส่ง `trigger.set` ชนิด `idle` ที่มีชิ้นใหม่ต่อท้าย และหน้าแสดงลิสต์ใหม่หลังได้ `trigger.listed`

#### Scenario: ลากชิ้นขึ้นเป็นชิ้นแรก
- **WHEN** Member ลากชิ้นที่สองขึ้นไปเหนือชิ้นแรกแล้วปล่อย
- **THEN** Controller ส่ง `trigger.set` ที่มีชิ้นนั้นเป็นชิ้นแรก และแถวแสดงลำดับใหม่ทันทีโดยไม่รอ `trigger.listed`

#### Scenario: ทำชิ้นที่ไม่เสร็จใหม่
- **WHEN** ชิ้นหนึ่งมีสถานะ `timedOut` แล้ว Member กดทำชิ้นนี้ใหม่
- **THEN** ชิ้นนั้นกลับเป็น `pending` ที่ตำแหน่งเดิม

### Requirement: ร่างจาก Agent
เมื่อ `trigger.listed` มี `draft` หน้า Idle Work SHALL แสดงร่างเหนือลิสต์ กดแล้ว SHALL เปิด sheet เดียวที่แสดงทุกเรื่องที่เสนอ ให้แก้ข้อความและเลือกเก็บหรือไม่เก็บทีละเรื่อง การบันทึกต่อเรื่องที่เลือกไว้ท้ายลิสต์ และเพราะการเซ็นลิสต์ล้างร่างทั้งหมด เรื่องที่ไม่เลือกจึงหายไปด้วย ร่าง SHALL ไม่ถูกส่งไปรันจนกว่า Member จะบันทึก

#### Scenario: เก็บบางเรื่องเข้าลิสต์
- **WHEN** Agent เสนอสองเรื่อง แล้ว Member เลือกเก็บเรื่องแรกและบันทึก
- **THEN** ลิสต์ที่เซ็นมีเรื่องแรกต่อท้าย และร่างหายไปทั้งหมด
