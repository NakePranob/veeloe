# controller-i18n Specification

## Purpose

กำหนดว่า Controller แสดงข้อความในภาษาของ Member อย่างไร และป้องกันอย่างไรไม่ให้ข้อความขาดในภาษาใดภาษาหนึ่ง รวมถึงการแปล code ที่ Runtime และ Hub ส่งมา

## Requirements

### Requirement: ภาษาเริ่มจากเครื่องและเปลี่ยนในแอปได้
Controller SHALL เริ่มที่ภาษาแรกของเครื่องที่รองรับ และเริ่มที่ภาษาอังกฤษเมื่อไม่รองรับ Member SHALL เปลี่ยนภาษาในแอปได้ ค่านี้ SHALL เป็นของเครื่องนั้นและมีผลทันทีโดยไม่ต้องเปิดแอปใหม่

#### Scenario: เครื่องภาษาไทย
- **WHEN** เครื่องตั้งภาษาไทย และยังไม่เคยเลือกภาษาในแอป
- **THEN** แอปแสดงภาษาไทย

#### Scenario: เครื่องใช้ภาษาที่ยังไม่รองรับ
- **WHEN** เครื่องตั้งภาษาที่แอปยังไม่รองรับ และยังไม่เคยเลือกภาษาในแอป
- **THEN** แอปแสดงภาษาอังกฤษ

#### Scenario: เปลี่ยนภาษาในแอป
- **WHEN** Member เลือกภาษาในหน้าตั้งค่า
- **THEN** ทุกหน้าจอที่เปิดอยู่เปลี่ยนภาษาทันที และเปิดแอปครั้งถัดไปยังเป็นภาษาที่เลือก

#### Scenario: คำขาดในภาษาที่เลือก
- **WHEN** ภาษาที่เลือกไม่มี key หนึ่ง
- **THEN** แอปแสดงคำนั้นเป็นภาษาอังกฤษ ไม่แสดงตัว key

### Requirement: ข้อความอยู่กับเจ้าของและครบทั้งสองภาษา
ข้อความของแต่ละ slice SHALL อยู่ใน slice นั้น และโค้ด SHALL เรียกข้อความด้วย key ที่ตรวจด้วย type CI SHALL ล้มเมื่อภาษาไทยกับอังกฤษมี key หรือตัวแปรไม่ตรงกัน โดยไม่ถือว่ารูปพหูพจน์ที่ต่างกันตามภาษาเป็นความไม่ตรง

#### Scenario: เรียก key ที่ไม่มี
- **WHEN** โค้ดเรียก key ที่ไม่มีในข้อความของ slice
- **THEN** การตรวจ type ล้ม

#### Scenario: เพิ่มคำภาษาเดียว
- **WHEN** key หนึ่งมีในภาษาอังกฤษแต่ไม่มีในภาษาไทย หรือกลับกัน
- **THEN** CI ล้มและบอก slice กับ key นั้น

#### Scenario: ไฟล์ภาษาหาย
- **WHEN** slice หนึ่งมีข้อความภาษาเดียว
- **THEN** CI ล้มและบอก slice นั้น

#### Scenario: ตัวแปรไม่ตรงกัน
- **WHEN** ข้อความของ key เดียวกันใช้ตัวแปรต่างกันในสองภาษา
- **THEN** CI ล้มและบอก key นั้น

#### Scenario: รูปพหูพจน์ต่างกัน
- **WHEN** ภาษาอังกฤษมีรูป `_one` กับ `_other` และภาษาไทยมีแค่ `_other` ของ key เดียวกัน
- **THEN** CI ผ่าน

### Requirement: คำใน glossary คงเป็นภาษาอังกฤษ
ข้อความทุกภาษา SHALL ใช้คำใน `CONTEXT.md` เป็นภาษาอังกฤษตามที่เขียนไว้

#### Scenario: ข้อความภาษาไทยที่พูดถึง Machine
- **WHEN** หน้าจอภาษาไทยพูดถึง Machine
- **THEN** ข้อความใช้คำว่า Machine ไม่ใช้คำแปล

### Requirement: แอปเป็นคนแปล code จาก Protocol
Controller SHALL แปล code กับค่าประกอบที่ Runtime และ Hub ส่งมาเป็นข้อความในภาษาของ Member และ SHALL แสดงข้อความกลางพร้อม code เมื่อไม่รู้จัก code นั้น

#### Scenario: code ที่รู้จัก
- **WHEN** ได้รับ `hub.machine_offline`
- **THEN** แอปได้ข้อความที่บอกว่า Machine ออฟไลน์ในภาษาที่เลือก

#### Scenario: code ที่ไม่รู้จัก
- **WHEN** ได้รับ code ที่แอปรุ่นนี้ไม่รู้จัก
- **THEN** แอปได้ข้อความกลางที่มี code นั้น ไม่ crash และไม่แสดงข้อความว่าง
