# สิ่งที่ต้องลองด้วยมือ

ไฟล์นี้จดสิ่งที่ต้องใช้ Provider จริงหรือเครื่องจริง ส่วนฝั่งโค้ดตรวจด้วย unit test ของ protocol, budget module, proxy, task-message, agents slice, ฐานข้อมูลของ Controller และ machine-link พร้อม e2e ที่ใช้ Hub กับ Provider ตัวแทนแล้ว (`e2e/agent-task.test.ts` ข้อ Budget)

หน้าจอยังไม่ได้เปิดบน iOS Simulator หรือเว็บจริง เพราะต้องมี Machine ที่ Pair แล้วและ Provider จริง ข้อ 2 ทั้งหมดจึงยังรอเจ้าของกดดู และข้อ 1 กับ 3 ก็ยังต้องลองกับ Provider จริง

repo นี้เป็น public เมื่อรายงานผล ให้ระบุแค่เครื่อง รุ่น OS ข้อที่ลอง และผลที่ได้ และอย่าใส่ key ของ Provider ลิงก์ Pairing หรือเนื้อหาแชตที่เป็นความลับ

## เตรียม

ทำตาม `openspec/changes/archive/2026-11-05-agent-and-task/manual-checks.md` ให้มี Agent ที่คุยกับ Provider จริงได้ก่อน แล้วรัน `veeloe` ใน `VEELOE_HOME` เดิม

## 1. Provider จริง

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 1.1 | คุยหนึ่งข้อความ แล้วเทียบยอดในหน้า Agent กับหน้า usage ของ Provider | ตัวเลขตรงกันในระดับ K เพราะนับ input, cache และ output ครบ |
| 1.2 | ตั้ง Budget 0.01 (10K token) ที่หน้า Agent แล้วกดบันทึก แล้วขอให้ Agent เขียนยาวหลายข้อความ | Task แสดงการ์ด Budget หมด คำตอบที่ได้ไปแล้วยังอยู่ และส่งข้อความถัดไปขึ้นว่าส่งไม่สำเร็จเพราะ Budget หมด |
| 1.3 | กดเพิ่ม Budget ในการ์ด ตั้ง 10 แล้วกดบันทึก แล้วพิมพ์ต่อใน Task เดิม | Agent ตอบต่อจากบทสนทนาเดิม |
| 1.4 | ใช้ Provider แบบ gateway เช่น OpenRouter | ยอดขยับหลังคำตอบ ถ้าไม่ขยับ ให้จดว่า gateway ไม่ส่ง `usage` |

## 2. iPhone จริง

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 2.1 | หน้า Agent: แตะช่อง Budget พิมพ์ทศนิยม แล้วกดบันทึก | คีย์บอร์ดเป็นตัวเลขที่มีจุด ปุ่มบันทึกที่หัวหน้าไม่ถูกคีย์บอร์ดบัง และคีย์บอร์ดปิดเมื่อกดบันทึก |
| 2.2 | ดูหน้า Agent ระหว่าง Turn | แถบกับตัวเลขขยับหลัง LLM ตอบแต่ละครั้ง โดยไม่ต้องออกจากหน้า |
| 2.3 | ปิดเน็ตแล้วเปิดหน้า Agent | เห็นยอดล่าสุดที่เคยได้ และกดบันทึกไม่ได้ |
| 2.4 | หน้า Task: พิมพ์ข้อความแล้วกดส่ง | ข้อความขึ้นใน Task และคีย์บอร์ดปิดทันที |

## 3. Machine

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 3.1 | ดู `runtime/usage.json` และ `runtime/agents.json` | สิทธิ์ 0600, ยอดของวันนี้ และ `budget` ที่ตั้งจากแอปด้วยปุ่มบันทึก |
| 3.2 | Ctrl-C แล้วเปิด `veeloe` ใหม่ | ยอดของวันนี้เท่าเดิม |
| 3.3 | ตั้งเวลาเครื่องเป็น 03:58 คุยหนึ่งข้อความ รอเลย 04:00 แล้วขอ `agent.list` จากแอป (เปิดแอปใหม่) | ยอดเริ่มจาก 0 โดยไม่ต้องเริ่ม `veeloe` ใหม่ |
