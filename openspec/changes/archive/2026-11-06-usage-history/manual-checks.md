# สิ่งที่ต้องลองด้วยมือ

ฝั่งโค้ดตรวจด้วย unit test ของ protocol, store, slice, ฐานข้อมูลของ Controller, machine-link และกราฟ พร้อม e2e ที่ใช้ Hub กับ Provider ตัวแทนแล้ว (`e2e/agent-task.test.ts` ข้อ `usage.list`) ส่วนที่เหลือต้องใช้ Provider จริงและตาจริงบน iPhone กับเว็บ

repo นี้เป็น public เมื่อรายงานผล ให้ระบุแค่เครื่อง รุ่น OS ข้อที่ลอง และผลที่ได้ อย่าใส่ key ของ Provider ลิงก์ Pairing หรือเนื้อหาแชต

## เตรียม

ทำตาม `openspec/changes/daily-budget/manual-checks.md` ให้มี Agent ที่คุยกับ Provider จริงได้ แล้วคุยสอง Task ให้มี token อย่างน้อยหนึ่งวัน จากนั้นรัน `veeloe` ตัวใหม่ (build จาก change นี้) ใน `VEELOE_HOME` เดิม

## 1. หน้า "การใช้ token"

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 1.1 | เปิด Workspace แล้วแตะ "การใช้ token" | หน้าเปิดด้วยช่วง 7 วัน และมีแถวของ Machine ที่มี Agent |
| 1.2 | สลับ 1, 3, 7, 30 วัน | กราฟเปลี่ยนความยาวตามช่วง และตัวเลขรวมของแต่ละ Machine เปลี่ยนตาม |
| 1.3 | ดูแท่งของวันที่ไม่มีคำตอบเลย | เป็นร่องว่าง ไม่ใช่แท่งศูนย์ และอ่านด้วย screen reader ได้ว่า "ไม่มีข้อมูล" |
| 1.4 | ปิดแอปแล้วเปิดใหม่ | ยังเลือกช่วงเดิม (จดจำบนเครื่อง) |
| 1.5 | แตะแถว Agent ใต้ Machine | เปิดหน้าของ Agent นั้น |

## 2. งานที่ใช้ token

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 2.1 | คุยสอง Task ที่ใช้ token ต่างกันมาก | "งานที่ใช้ token มากที่สุด" เรียงจากมากไปน้อย พร้อมชื่อ Agent |
| 2.2 | ดู Task ที่ Controller ยังไม่มีข้อมูล | แสดงรหัสสั้น ๆ ของ Task ไม่ใช่ชื่อปลอม |
| 2.3 | ดูแถว "อื่น ๆ" | มียอดเท่ากับผลรวมของช่วงลบด้วยยอดของ Task ที่แสดง ไม่หายไปเงียบ ๆ |

## 3. ออฟไลน์และความสดของข้อมูล

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 3.1 | ปิด `veeloe` แล้วเปิดหน้าใหม่ | เห็นยอดที่แคชไว้พร้อม "ข้อมูลเมื่อ …" และบอกว่า Machine ออฟไลน์ |
| 3.2 | เปิดแอปใหม่ตอนออฟไลน์ทั้งที่เคยมีข้อมูล | ยังเห็นกราฟกับยอดของ Agent จากแคช |
| 3.3 | เปิดแอปครั้งแรกตอนออฟไลน์และยังไม่เคยได้ข้อมูล | บอกว่ายังไม่มีข้อมูล ไม่ใช่กราฟว่างเปล่าเงียบ ๆ |
| 3.4 | เปิด `veeloe` กลับมาแล้วกด "ลองใหม่" | ตัวเลข refreshed และเวลาที่ได้ล่าสุดเปลี่ยน |

## 4. เขตเวลาและวันของ Budget

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 4.1 | ตั้ง `TZ` ของ Machine เป็นอีกเขตเวลาที่ต่างจากมือถือ แล้วคุยหนึ่งข้อความ | `from`/`to` ของกราฟเป็นวันของ Machine ไม่ใช่วันของมือถือ |
| 4.2 | เริ่มคุยก่อน 04:00 แล้วดูอีกครั้งหลัง 04:00 | ยอดของวันใหม่แยกจากวันก่อน และกราฟมีสองแท่งตามวันของ Budget |
| 4.3 | ตั้ง Budget ต่ำให้หมด แล้วดูหน้านี้ | ยังแสดง token ที่ใช้จริง (หน้านี้ไม่บังคับ Budget และไม่มีเปอร์เซ็นต์) |

## 5. สิทธิ์และคำ

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 5.1 | เปิดหน้าทั้งภาษาไทยและอังกฤษ | ทุกคำแปลครบ รวมข้อความ "ข้อมูลเมื่อ" และ "อื่น ๆ" |
| 5.2 | วันที่ v0.1 มี Owner คนเดียว | เห็น Agent ทุกตัวบนเครื่องที่ Pair ไว้ |
| 5.3 | ดูว่ามีตัวเลขเงินไหม | ไม่มีสกุลเงินหรือราคา มีแต่ token |
