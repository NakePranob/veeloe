# สิ่งที่ต้องลองด้วยมือ

ไฟล์นี้จดสิ่งที่ agent ลองเองไม่ได้ ได้แก่ Provider จริงที่มีหลาย model, การลบ Provider ที่หน้าเครื่องแล้วกลับมาแก้จากมือถือ และการเห็นค่าใหม่บนเครื่องที่สองของ Owner ส่วนการตรวจคำสั่ง การตรึง model ต่อ Task และการย้าย Provider agent ตรวจด้วย unit test กับ e2e ที่ใช้ Provider ตัวแทนแล้ว หน้าจอยังไม่ได้ลองบน iOS Simulator และเว็บจนกว่า task 3.6 จะเสร็จ

repo นี้เป็น public เมื่อรายงานผล ให้ระบุแค่เครื่อง รุ่น OS ข้อที่ลอง และผลที่ได้ อย่าใส่ key หรือ URL ของ Provider

## เตรียม

เตรียม Hub และติดตั้งแอปลง iPhone ตาม `openspec/changes/machine-pairing/manual-checks.md` หัวข้อ เตรียม Hub ให้ iPhone ต่อถึง ทำ Pairing จาก iPhone แล้ว Link เบราว์เซอร์บน Mac ตาม `openspec/changes/linking-and-revocation/manual-checks.md` หัวข้อ 1 บน Machine ตั้ง Provider สองตัวด้วย `veeloe provider add` ตัวหนึ่งต้องมี model อย่างน้อยสองตัว แล้วสร้าง Agent ที่ใช้ Provider ตัวแรก

## 1. ชื่อและ Character

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 1.1 | บน iPhone เปิดหน้า Agent แก้ชื่อเป็น Deployer แล้วกดบันทึก | เห็นว่ากำลังบันทึก แล้วหัวของหน้าเป็น Deployer |
| 1.2 | ดูหน้า Agent เดียวกันบนเว็บ | ชื่อเป็น Deployer โดยไม่ต้องรีเฟรช |
| 1.3 | เริ่ม Task ใหม่แล้วถามว่า "คุณชื่ออะไร" | Agent ตอบว่าชื่อ Deployer |
| 1.4 | ลบชื่อจนว่าง | ปุ่มบันทึกใช้ไม่ได้ |
| 1.5 | กดแถว Character เปลี่ยนสีกับเปลือก แล้วกดยกเลิก | Character เท่าเดิมทั้งบน iPhone และเว็บ |
| 1.6 | เปลี่ยนอีกครั้งแล้วกด เสร็จ | หน้าปิดหลัง Machine ตอบ และ Inbox บนทั้งสองเครื่องเห็นหน้าตาใหม่ |
| 1.7 | ดูแถวตัวอย่าง Mood ในหน้าแก้ Character ทั้งไทยและอังกฤษ บนจอ 375pt | ป้ายทุกตัวอ่านได้ ไม่ล้นแถว |

## 2. Provider และ model

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 2.1 | เริ่ม Task A แล้วคุยหนึ่งข้อความ จากนั้นไปหน้า Provider และ model ติ๊ก model อื่นแล้วกดบันทึก | หน้า Agent แสดง model ใหม่ และ footer บอกว่ามีผลตั้งแต่ Task ถัดไป |
| 2.2 | พิมพ์ต่อใน Task A แล้วดูบิลหรือ log ของ Provider | คำขอของ Task A ยังเป็น model เดิม |
| 2.3 | เริ่ม Task B แล้วพิมพ์ | คำขอของ Task B เป็น model ใหม่ |
| 2.4 | หยุด `veeloe` แล้วรันใหม่ แล้วพิมพ์ต่อใน Task A | ยังเป็น model เดิม |
| 2.5 | เปลี่ยน model ขณะที่ Agent กำลังตอบข้อความยาว | Turn นั้นตอบจนจบ ไม่ถูกตัด |
| 2.6 | หยุด `veeloe` แล้วเปิดหน้า Provider และ model บน iPhone | บันทึกไม่ได้ และหน้าบอกว่า Machine ต้องออนไลน์ |

## 3. Provider ที่ถูกลบ

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 3.1 | บน Machine รัน `veeloe provider remove` กับ Provider ที่ Agent ใช้ | CLI บอกชื่อ Agent ที่ใช้อยู่ และบอกให้เลือก Provider ใหม่ที่หน้า Agent ในแอป |
| 3.2 | พิมพ์ใน Task A | Turn จบด้วยคำที่บอกให้เลือก Provider ใหม่ในหน้า Agent |
| 3.3 | เปิดหน้า Agent | เห็นคำเตือนว่า Provider ไม่อยู่บน Machine แล้ว และกดไปหน้าเลือกได้ ซึ่งไม่มีแถวไหนติ๊กอยู่ |
| 3.4 | เลือก Provider ตัวที่สองกับ model แล้วกดบันทึก | คำเตือนหายบนทั้ง iPhone และเว็บ |
| 3.5 | พิมพ์ต่อใน Task A | Agent ตอบด้วย Provider ตัวใหม่ |
