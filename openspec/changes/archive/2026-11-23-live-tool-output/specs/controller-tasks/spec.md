## ADDED Requirements

### Requirement: คำสั่งที่กำลังรันแสดง output ล่าสุด
ระหว่างที่คำสั่งกำลังรัน หน้า Task SHALL แสดงเวลาที่รันไปแล้วข้างคำสั่ง และเมื่อได้ `tool.output` ของคำสั่งนั้น SHALL แสดงบรรทัดท้ายของ output ใต้คำสั่งในกลุ่มที่หุบอยู่ และ SHALL อัปเดตเมื่อได้ข้อความใหม่ Controller SHALL เก็บ `tool.output` ไว้ในหน่วยความจำเท่านั้น และ SHALL แทนด้วยผลเต็มเมื่อได้ `tool.result` ของคำสั่งนั้น หน้าที่เปิดหลังคำสั่งเริ่มรัน SHALL แสดง output เมื่อได้ข้อความถัดไป และ SHALL ไม่ขอ output ย้อนหลัง

#### Scenario: เปิดดูระหว่าง test รัน
- **WHEN** Agent รัน `cargo test` ที่พิมพ์ผลทีละ test และ Owner เปิดหน้า Task อยู่
- **THEN** กลุ่มที่หุบอยู่แสดง `cargo test` พร้อมเวลาที่รันไปและบรรทัดล่าสุดของ output ที่เปลี่ยนตามที่ test เดิน

#### Scenario: คำสั่งจบ
- **WHEN** `tool.result` ของคำสั่งที่กำลังแสดง output สดมาถึง
- **THEN** หน้า Task แสดงผลเต็มของคำสั่งตามปกติ และไม่แสดง output สดของคำสั่งนั้นอีก

#### Scenario: เปิดแอปใหม่ระหว่างคำสั่งรัน
- **WHEN** Owner เปิดแอปใหม่ขณะคำสั่งยังรันอยู่
- **THEN** หน้า Task แสดงคำสั่งที่กำลังรันพร้อมเวลา และแสดง output เมื่อได้ `tool.output` ถัดไป
