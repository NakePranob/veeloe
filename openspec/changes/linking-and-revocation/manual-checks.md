# สิ่งที่ต้องลองด้วยมือ

ไฟล์นี้จดสิ่งที่ agent ลองเองไม่ได้ ได้แก่ การสแกน QR บนจอ iPhone ด้วยกล้องของอีกเครื่อง การแชร์ลิงก์ Face ID ก่อนเซ็น และ passkey บนเว็บจริง ส่วนคำขอ การอนุมัติ และ handoff กับ Hub จริงบน Postgres และ `veeloe` จริง agent ตรวจด้วย e2e แล้ว หน้าจอหลังกลับทิศ QR ยังไม่ได้ลองบน iOS Simulator และเว็บ (task 4.5)

repo นี้เป็น public เมื่อรายงานผล ให้ระบุแค่เครื่อง รุ่น OS ข้อที่ลอง และผลที่ได้ และอย่าใส่ลิงก์ `veeloe://link` เพราะมีรหัสลับ

## เตรียม

เตรียม Hub, Postgres และติดตั้งแอปลง iPhone ตาม `openspec/changes/machine-pairing/manual-checks.md` หัวข้อ เตรียม Hub ให้ iPhone ต่อถึง แล้วทำ Pairing จาก iPhone ให้เสร็จก่อน เปิด Controller บนเว็บจาก Mac เครื่องเดียวกันด้วย Safari หรือ Chrome

## 1. Link เบราว์เซอร์จาก iPhone

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 1.1 | บน iPhone ไปที่ Workspace แล้ว เครื่องของฉัน กด Link เครื่องใหม่ | เห็น QR ลิงก์ ปุ่มแชร์ลิงก์ และข้อความว่ารอเครื่องใหม่ |
| 1.2 | กด แชร์ลิงก์ แล้วส่งให้ Mac ของตัวเองด้วย AirDrop หรือ Notes | ได้ลิงก์ `veeloe://link?...` บน Mac |
| 1.3 | บนเว็บ สร้างกุญแจด้วย passkey แล้วกด ใช้กับเครื่องที่มีอยู่แล้ว วางลิงก์แล้วกด ถัดไป | ไม่มีช่อง Hub เห็นชื่อเครื่องเป็นชื่อเบราว์เซอร์ และแถว Hub เป็น `ws://<ip>:8090` จากลิงก์ |
| 1.4 | กด ขอ Link | เว็บบอกให้อนุมัติบนเครื่องเดิม และ iPhone เปลี่ยนเป็น มีเครื่องขอ Link พร้อมชื่อเบราว์เซอร์ที่แก้ได้ |
| 1.5 | กดอนุมัติแล้วยกเลิก Face ID | อยู่หน้าเดิม เว็บยังรอ และกดอนุมัติใหม่ได้ |
| 1.6 | กดอนุมัติแล้วยืนยัน Face ID | iPhone กลับไปที่ เครื่องของฉัน และเห็นเบราว์เซอร์ว่า Link โดย iPhone ส่วนเว็บเห็น Machine บนหน้าแรก |
| 1.7 | บนเว็บ เปิด Task ที่คุยค้างไว้บน iPhone แล้วพิมพ์ต่อ | เห็นบทสนทนาเดิม และ iPhone เห็นข้อความใหม่ |
| 1.8 | Link เครื่องใหม่อีกครั้ง แล้ววางลิงก์เดียวกันในอีกเบราว์เซอร์สองครั้ง | iPhone แสดงแค่คำขอแรก คำขอที่สองไม่ขึ้น |
| 1.9 | บน iPhone ที่มีเครื่องขอ Link กด ยกเลิก | ไม่มีอะไรถูก Link และเว็บรอจนหมดอายุ แล้วบอกให้สร้าง QR ใหม่บนเครื่องเดิม |
| 1.10 | ปิดหน้า Link เครื่องใหม่บน iPhone แล้วกด ขอ Link บนเว็บด้วยลิงก์เดิม | เว็บบอกว่าเครื่องเดิมไม่ได้แสดง QR นี้แล้ว |
| 1.11 | ให้ QR หมดอายุ (รอ 10 นาที) แล้ววางลิงก์บนเว็บ | iPhone บอกว่า QR หมดอายุ และเว็บปฏิเสธลิงก์ |
| 1.12 | มี iPad หรือ iPhone อีกเครื่องที่สร้างกุญแจแล้ว สแกน QR บน iPhone ด้วยแอปกล้อง | iOS ถามว่าจะเปิดใน Veeloe แล้วเข้าหน้า ใช้กับเครื่องที่มีอยู่แล้ว ที่อ่านลิงก์แล้ว |

## 2. Machine ที่ปิดอยู่

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 2.1 | หยุด `veeloe` แล้ว Link อีกแท็บหรือเบราว์เซอร์อื่น จากนั้นรัน `veeloe` ใหม่ | เบราว์เซอร์ใหม่สั่ง Agent ได้หลัง Machine กลับมา |
| 2.2 | หยุด `veeloe` แล้วถอนเบราว์เซอร์นั้นจาก iPhone จากนั้นรัน `veeloe` ใหม่ | เบราว์เซอร์ที่ถูกถอนบอกว่าเครื่องนี้ถูกถอนแล้ว และสั่งอะไรไม่ได้ |

## 3. ถอนกุญแจ

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 3.1 | บนเว็บ ถอน iPhone แล้วยกเลิก passkey | ไม่มีอะไรเปลี่ยน |
| 3.2 | บนเว็บ ถอน iPhone แล้วยืนยัน passkey | iPhone ที่เปิดแอปอยู่กลับไปหน้าสร้างกุญแจทันที และเว็บเห็น iPhone ในส่วน ถูกถอนแล้ว |
| 3.3 | บนเว็บที่เหลือเครื่องเดียว กดถอนเครื่องนี้ | แอปบอกว่าถอนไม่ได้ พร้อมทาง Link เครื่องอื่นหรือ `veeloe unpair` และเห็นคำเตือนเครื่องเดียว |
| 3.4 | Link iPhone กลับมาจากเว็บ แล้วถอนเว็บจากเว็บเอง | เว็บกลับไปหน้าสร้างกุญแจ และ iPhone ยังใช้ได้ |
