# สิ่งที่ต้องลองด้วยมือ

ไฟล์นี้จดสิ่งที่ agent ลองเองไม่ได้ ได้แก่ การสแกน QR บนจอเบราว์เซอร์ด้วยกล้องของ iPhone จริง Face ID ก่อนเซ็น และ passkey บนเว็บจริง ส่วนการวางลิงก์ Hub จริงบน Postgres และ `veeloe` จริง agent ลองแล้วบน iOS Simulator และ Chromium

repo นี้เป็น public เมื่อรายงานผล ให้ระบุแค่เครื่อง รุ่น OS ข้อที่ลอง และผลที่ได้ และอย่าใส่ลิงก์ `veeloe://link` เพราะมีรหัสลับ

## เตรียม

เตรียม Hub, Postgres และติดตั้งแอปลง iPhone ตาม `openspec/changes/machine-pairing/manual-checks.md` หัวข้อ เตรียม Hub ให้ iPhone ต่อถึง แล้วทำ Pairing จาก iPhone ให้เสร็จก่อน เปิด Controller บนเว็บจาก Mac เครื่องเดียวกันด้วย Safari หรือ Chrome

## 1. Link เบราว์เซอร์จาก iPhone

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 1.1 | บนเว็บ สร้างกุญแจด้วย passkey แล้วกด ใช้กับเครื่องที่มีอยู่แล้ว ใส่ Hub `ws://<ip>:8090` | เห็น QR กับลิงก์ และชื่อเครื่องเป็นชื่อเบราว์เซอร์ |
| 1.2 | บน iPhone ไปที่ Workspace แล้ว เครื่องของฉัน กด Link เครื่องใหม่ แล้วสแกน QR บนจอ Mac | เห็นชื่อเครื่องใหม่ที่แก้ได้ และปุ่มอนุมัติ |
| 1.3 | สแกน QR เดิมด้วยแอปกล้องของ iPhone แทน | iOS ถามว่าจะเปิดใน Veeloe แล้วเข้าหน้าเดียวกัน |
| 1.4 | กดอนุมัติแล้วยกเลิก Face ID | อยู่หน้าเดิม เว็บยังรอ และกดอนุมัติใหม่ได้ |
| 1.5 | กดอนุมัติแล้วยืนยัน Face ID | iPhone กลับไปที่ เครื่องของฉัน และเห็นเบราว์เซอร์ว่า Link โดย iPhone ส่วนเว็บเห็น Machine บนหน้าแรก |
| 1.6 | บนเว็บ เปิด Task ที่คุยค้างไว้บน iPhone แล้วพิมพ์ต่อ | เห็นบทสนทนาเดิม และ iPhone เห็นข้อความใหม่ |
| 1.7 | ให้ QR หมดอายุ (รอ 10 นาที) แล้วสแกน | iPhone ปฏิเสธลิงก์ และเว็บบอกว่าหมดอายุ |

## 2. Machine ที่ปิดอยู่

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 2.1 | หยุด `veeloe` แล้ว Link อีกแท็บหรือเบราว์เซอร์อื่น จากนั้นรัน `veeloe` ใหม่ | เบราว์เซอร์ใหม่สั่ง Agent ได้หลัง Machine กลับมา |
| 2.2 | หยุด `veeloe` แล้วถอนเบราว์เซอร์นั้นจาก iPhone จากนั้นรัน `veeloe` ใหม่ | เบราว์เซอร์ที่ถูกถอนบอกว่าเครื่องนี้ถูกถอนแล้ว และสั่งอะไรไม่ได้ |

## 3. ถอนกุญแจ

| ข้อ | ทำอะไร | ควรเห็น |
|---|---|---|
| 3.1 | บนเว็บ ถอน iPhone แล้วยกเลิก passkey | ไม่มีอะไรเปลี่ยน |
| 3.2 | บนเว็บ ถอน iPhone แล้วยืนยัน passkey | iPhone ที่เปิดแอปอยู่กลับไปหน้าสร้างกุญแจทันที และเว็บเห็น iPhone ในส่วน ถูกถอนแล้ว |
| 3.3 | บนเว็บที่เหลือเครื่องเดียว กดถอนเครื่องนี้ | แอปบอกว่าถอนไม่ได้ พร้อมทาง Link เครื่องอื่นหรือ `veeloe unpair` และเห็นคำเตือนเครื่องเดียว |
| 3.4 | Link iPhone กลับมาจากเว็บ แล้วถอนเว็บจากเว็บเอง | เว็บกลับไปหน้าสร้างกุญแจ และ iPhone ยังใช้ได้ |
