## Operational Notes

- Local Postgres comes from `docker-compose.yml`

- The schema is the migrations', in every environment: `migrate up` applies
  it and the startup version check refuses to boot without it. There is no
  development table bootstrap

- `docs/openapi.yaml` is hand-written, not generated — update it whenever an
  endpoint or DTO changes
- Versions above are what `go-scaffold create` pinned in `go.mod` — bump them
  by hand (`go get -u` + `go mod tidy`) as the stack evolves
- Each `go-scaffold add ...` command pins its own dependencies the same way
  (River/Asynq, JWT, oauth2, Prometheus, OpenTelemetry, ...), so `go mod tidy`
  resolves them to the versions that feature was built against instead of
  whatever happened to be newest that day. The full list is `go.mod`; this
  table only covers what `create` itself brings in
- Auth, worker, and RBAC are opt-in. Their `add` commands update this snapshot
  when the generated file is untouched; hand-edited docs are left alone and
  require a manual update.
