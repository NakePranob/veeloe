# ปลดล็อกครั้งเดียวตอบ Approval ทั่วไปได้ห้านาที ส่วนการขยายสิทธิ์ยังต้องปลดล็อกทุกครั้ง

Status: proposed

> แก้ ADR 0012 บางส่วน ตามที่เขียนไว้ในหัวของ ADR นั้น

ADR 0012 ให้กุญแจของ Controller ใช้ได้หลังยืนยันตัว และการตอบ Approval ต้องปลดล็อกใหม่ทุกครั้ง เพื่อไม่ให้ใครที่หยิบมือถือที่ปลดล็อกอยู่ไปอนุมัติแทนได้ งานที่มี Approval ติดกันหลายรายการ เช่น research ที่เจอหลายโดเมน จึงต้องสแกนหน้าซ้ำหลายรอบในไม่กี่นาที OpenBot (nightly-labs/openbot) ไม่ถามยืนยันตัวเลย การกดอนุมัติเป็นแค่การกดปุ่ม เราไม่ไปทางนั้น แต่แยกการตัดสินใจรายวันออกจากการขยายสิทธิ์ (เจ้าของตัดสิน 2026-11-28)

**ช่วงห้านาที** หลังปลดล็อกเพื่อตอบ Approval ทั่วไป Controller ตอบ Approval ทั่วไปรายการถัดไปได้โดยไม่ปลดล็อกอีกภายในห้านาที ช่วงนี้นับจากการปลดล็อกครั้งล่าสุด ไม่ต่อเวลาเองตอนกดตอบ และหมดทันทีเมื่อแอปไปอยู่เบื้องหลัง จอล็อก หรือเปลี่ยน Workspace Approval ทั่วไปคือ อนุญาตครั้งเดียว, อนุญาตทั้ง Task (ADR 0088), ปฏิเสธ และบอกให้ทำอย่างอื่น

**ปลดล็อกทุกครั้ง** การกระทำต่อไปนี้ปลดล็อกใหม่ทุกครั้ง ไม่ว่าจะอยู่ในช่วงห้านาทีหรือไม่: อนุญาตตลอด (เข้า Allowlist หรือ Egress), แก้ Allowlist, Egress หรือระดับไฟล์ (ADR 0087), แจกหรือถอน Grant, เชิญหรือลบ Member, Linking, Revocation, Pairing และตั้งหรือแก้ Trigger ทุกชนิด

**การปฏิเสธไม่ต้องปลดล็อก** เหมือนเดิม

**ไม่ใช่การล็อกแอป** ล็อกแอปเมื่อไม่ได้ใช้ห้านาที (spec `controller-device-key`) ยังเหมือนเดิม และเป็นคนละอย่างกัน ล็อกแอปกันการเปิดดูแอป ช่วงห้านาทีนี้แค่ข้ามการปลดล็อกซ้ำตอนตอบ Approval ทั่วไป ถ้าแอปล็อกเองก่อนครบห้านาที ช่วงนี้หมดไปด้วย

## Considered Options

- **ไม่ปลดล็อกเลยแบบ OpenBot**: เร็วที่สุด แต่มือถือที่เปิดค้างไว้อนุมัติคำสั่งบนเครื่องของเจ้าของได้
- **ช่วงยาวกว่า เช่น 30 นาที**: กดน้อยลงอีก แต่ครอบช่วงที่มือถือวางทิ้งไว้บนโต๊ะได้
- **คงปลดล็อกทุกครั้ง**: ปลอดภัยที่สุด แต่คนจะเลือกอนุญาตตลอดเพื่อหนีการสแกนหน้า ซึ่งแย่กว่า

## Consequences

- ต้องแก้ scenario "ต้องยืนยันตัวก่อนอนุมัติ" ใน spec `approvals` ให้ยกเว้น Approval ทั่วไปในช่วงห้านาที
- ห้านาทีเป็นค่าตายตัวใน v0.x ยังไม่ให้ตั้ง
- ลายเซ็นของทุก Approval ยังมาจากกุญแจเดิม Machine ไม่รู้และไม่ต้องรู้ว่าตอบในช่วงห้านาทีหรือเปล่า
- ต้องใช้กุญแจที่ปลดได้แบบมีเวลา บน iOS เป็น `LAContext` ที่ใช้ซ้ำได้ตามช่วง (`touchIDAuthenticationAllowableReuseDuration`) บน Android เป็นกุญแจที่ตั้ง `setUserAuthenticationParameters` ด้วยเวลา ถ้าทำแบบนั้นไม่ได้บนเครื่องไหน เครื่องนั้นปลดล็อกทุกครั้งเหมือนเดิม
