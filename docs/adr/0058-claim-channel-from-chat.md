# รับแชตจากในแชตด้วย /claim

Agent ที่ถูกเชิญเข้ากลุ่มยังไม่มีคนรับผิดชอบ จะให้ Member กลับไปเปิดแอปเพื่อผูก Channel (ADR 0028) ก็ทำได้ แต่คนในแชตไม่รู้ว่าต้องทำอะไร ทิศที่เลือกคือ bot ที่ถูกเพิ่มเข้ากลุ่มแล้วยังไม่มีคนผูก จะเงียบทุกอย่างยกเว้นบรรทัดเดียวว่า "มีคนอยากให้รับแชตนี้ พิมพ์ /claim" Member ที่มี Use ขึ้นไปบน Agent ตัวนั้น (ADR 0010) พิมพ์ `/claim` ในแชตได้ แอป Controller จะแจ้งเตือนไปที่ Member ที่มี Manage แล้ว Manager คนหนึ่งกดยืนยันและเซ็นในแอป (ADR 0006) พอยืนยัน binding ก็เสร็จ งานหลังจากนั้นเดินในนามของ Manager ที่เซ็น เหมือนการผูก Channel ในแอปตาม ADR 0028 ทุกอย่าง ทั้งการตรวจ Use ว่าเป็นของคนเซ็น Task ขึ้น Inbox ของคนเซ็น และค่า token ตกที่ key ของคนเซ็น (เจ้าของตัดสิน 2026-11-01: Use เริ่มได้ แต่ต้องมี Manager เซ็นในแอปเสมอ)

แต่ละแชตมีสถานะรอรับ (pending-claim) ได้หนึ่งสถานะ หมดอายุตามค่าเริ่มต้น 24 ชั่วโมง ถ้าหมดเวลาแล้วยังไม่มีใครมารับ bot ออกจากกลุ่มเอง แชตหนึ่งมีคนรับได้คนเดียว ถ้ามีคนรับแล้ว คำสั่ง `/claim` ซ้ำไม่มีผล กุญแจที่เซ็นถูกถอนเมื่อไร Channel หยุดทันทีตาม ADR 0028 เดิม งบ token ยังใช้เพดานของ Agent (ADR 0043) และขอบเขต Workspace (ADR 0031) เหมือนเดิมทุกอย่าง

ตัดสินแล้ว (เจ้าของ 2026-11-01): Member ที่มีแค่ Use เริ่ม `/claim` ได้ แต่ binding เสร็จต้องมี Manager เซ็นในแอปเสมอ งานเดินในนาม Manager ที่เซ็น

## Considered Options

- **ผูกจากในแอปอย่างเดียวเหมือน ADR 0028 ปัจจุบัน**: ปลอดภัยสุด ไม่ต้องแตะ bot แต่คนในแชตไม่รู้ว่าต้องทำอะไร และคนที่เชิญ bot เข้ากลุ่มอาจไม่ใช่คนที่จะรับผิดชอบ
- **ใครในแชตก็พิมพ์ /claim แล้วได้เลย ไม่ต้องยืนยันในแอป**: ง่ายสุด แต่ไม่มีลายเซ็น (ADR 0006) ไม่รู้ว่ารับในนามใคร และใครยึดบัญชีแชตได้ก็ผูกได้
- **เชิญ bot แล้วผูกอัตโนมัติกับคนที่เชิญ**: ไม่ต้องพิมพ์อะไร แต่คนเชิญอาจไม่มี Manage และไม่รู้ตัวว่ารับผิดชอบค่า token ไปแล้ว
- **Use เริ่ม /claim แล้ว Manager เซ็นในแอป (ทางที่เลือก)**: คนในแชตเริ่มได้เองไม่ต้องรอ Manage มาพิมพ์ แต่ binding เสร็จต้องมี Manager เซ็นเสมอ งานเดินในนาม Manager ที่เซ็น
- **pending-claim ไม่มีหมดอายุ**: ไม่ต้องรีบรับ แต่ bot ค้างในกลุ่มที่ไม่รู้ว่าใครรับผิดชอบ และคนในแชตอาจเรียก Agent ที่ไม่มีวันเดิน
- **แชตหนึ่งมีคนรับได้หลายคน**: แบ่งค่า token กันได้ แต่ Task ของวัน (ADR 0028) จะไม่รู้ว่าเป็นงานของใคร Inbox กระจาย และ Approval ไม่รู้ต้องไปหาใคร

## Consequences

- bot ที่ยังไม่มีคนผูกตอบแค่บรรทัดรอรับแชต ไม่ตอบคำถามอื่น ไม่เปิด Task จนกว่าจะมีคนรับ
- แชตหนึ่งมีสถานะรอรับได้หนึ่งสถานะ มีคนรับได้คนเดียว หมดอายุตามค่าเริ่มต้น 24 ชั่วโมง หมดเวลาแล้ว bot ออกจากกลุ่มเอง
- การรับต้องยืนยันและเซ็นใน Controller ของคนรับ (ADR 0006) งานหลังจากนั้นเหมือน Channel ที่ผูกในแอปทุกอย่าง (ADR 0028)
- งบ token ยังใช้เพดานของ Agent (ADR 0043) และหยุดทันทีเมื่อกุญแจที่เซ็นถูกถอน
- Use เริ่ม `/claim` ได้ แต่ binding เสร็จต้องมี Manager เซ็นในแอปเสมอ (ตัดสินแล้ว เจ้าของ 2026-11-01)
