# push ไปหาเฉพาะคนที่เรื่องนั้นรออยู่หรือเป็นเรื่องของเขา

Member อยู่บนมือถือ และ Agent ทำงานนานโดยไม่มีคนดู ถ้าไม่มี push คนจะไม่รู้ว่างานเสร็จหรือมีอะไรรออยู่ ถ้ามีทุกเรื่อง push จะดังทั้งวันจนคนปิดทิ้ง เราจึงส่ง push เฉพาะเรื่องที่รอคนนั้นอยู่หรือเป็นเรื่องของเขาเอง Runtime เป็นคนเลือกผู้รับจาก Grant ที่ถืออยู่ (ADR 0034) และ push ยังไม่มีเนื้อหาจนกว่าจะมี E2E (ADR 0005)

| เรื่อง | ส่งให้ |
|---|---|
| Approval รออยู่ | คนที่มี Approve ที่ Agent ตัวนั้น |
| Turn เสร็จ ตอนที่ไม่ได้เปิดแอปอยู่ | คนที่ส่งข้อความของ Turn นั้น |
| ถูก Mention | คนที่ถูกแท็ก ไม่ว่าคนหรือ Agent เป็นคนแท็ก (ADR 0046) |
| Schedule มีเรื่องจะบอก | คนที่ตั้ง หรือทุกคนที่มี Use ที่ Agent นั้น ถ้าตอนตั้งเลือกไว้ |
| Budget ถึง 80% หรือหมด, Connector ต้อง login ใหม่, Agent เสนอ Skill ใหม่ | คนที่มี Manage |

Task จาก Channel ไม่ส่ง push ยกเว้น Approval เพราะถ้าแชตคุยกับ bot ทั้งวัน คนที่ผูกจะโดน push ตลอด Task ของคนอื่นก็ไม่ส่ง แม้จะเห็นได้ ยกเว้นถูก Mention Member ปิด push ได้ทั้งหมวด หรือปิดเฉพาะ Agent บางตัว ค่านี้เป็นของ Member และ sync ทุกเครื่องผ่าน Hub แต่ละเครื่องปิดเสียงแจ้งเตือนของตัวเองได้ (ADR 0053) ส่วนช่วงห้ามรบกวนใช้ Focus หรือ Do Not Disturb ของเครื่อง ไม่ทำเอง เมื่อเรื่องที่รออยู่จบแล้ว เช่น Approval ถูกตอบจากเครื่องอื่น Runtime ส่ง silent push ให้ลบแจ้งเตือนที่ค้างบนทุกเครื่อง

## Considered Options

- **push แค่ Approval ที่เหลือดูใน Inbox**: เงียบที่สุดและไม่ต้องมีหน้าตั้งค่า แต่สั่งงานยาวแล้ววางมือถือจะไม่รู้ว่างานเสร็จ
- **ให้ Schedule เลือกคนรับเป็นรายคน**: แม่นกว่า แต่ต้องมีหน้าเลือกคนและคอยแก้รายชื่อเมื่อ Grant เปลี่ยน ทางเลือก "ทุกคนที่มี Use" ไม่ได้ทำให้ใครเห็นอะไรเพิ่ม เพราะคนที่มี Use เห็นทุก Task อยู่แล้ว

## Consequences

- Agent Mention คนได้ Agent ที่โดนหลอกจึงพยายามส่ง push ถี่ได้ ADR 0046 กันไว้ด้วยการไม่ส่ง push ซ้ำจนกว่า Mention ก่อนหน้าจะถูกอ่าน
