# ลิงก์แชร์ Agent + หน้า Agent ที่แชร์กับฉัน

การให้คนอื่นใช้ Agent วันนี้ต้องให้ Owner มากดให้สิทธิ์ทีละคน (ADR 0010) ซึ่งช้าเมื่ออยากแชร์ให้เพื่อนลอง ทิศที่เสนอคือ Member ที่มี Manage บน Agent ตัวนั้น (ADR 0010) สร้างลิงก์แชร์จากในแอปได้ ตั้งได้ว่าใช้ได้ครั้งเดียวหรือหลายครั้ง หมดอายุตามค่าเริ่มต้น 24 ชั่วโมง และยกเลิกเมื่อไรก็ได้ คนที่เปิดลิงก์จะได้สร้างกุญแจของตัวเอง (ADR 0013) ได้เป็น Member และได้ Use บน Agent ตัวนั้นในขั้นตอนเดียว ไม่ต้องรอ Owner มากดให้แยกอีกที งานที่เขาสั่งเดินในนามของเขาเอง ตรวจ Use ของเขา Task ขึ้น Inbox ของเขา และค่า token ตกที่ key ของเขา เหมือนงานปกติทุกอย่าง (ADR 0006)

ลิงก์ที่หลุดคือความเสี่ยงหลัก ใครได้ลิงก์ไปก็ได้ Use บน Agent ตัวนั้น จึงต้องมีสามอย่าง คือหมดอายุสั้นตามค่าเริ่มต้น ยกเลิกได้ทันที และหน้ารายการลิงก์ที่ Owner เห็นว่าใครออกกุญแจอะไรไปบ้าง ใครใช้แล้วบ้าง ถ้าเห็นว่าหลุดก็กดยกเลิก ลิงก์ที่หมดอายุหรือถูกยกเลิกแล้วเปิดไม่ได้ ส่วนคนที่ได้สิทธิ์ไปแล้วยังอยู่ Owner ต้องถอน Use แยก (ADR 0031) หน้า Agent ในแอปต้องบอกให้ชัดตอนออกกุญแจว่าลิงก์นี้ให้ใครก็ใช้ได้จนกว่าจะหมดอายุหรือยกเลิก

คนที่ได้ Use จากหลาย Agent ควรมีหน้า "Agent ที่แชร์กับฉัน" รวม Agent ที่ตัวเองมี Use ไว้ที่เดียว ปักหมุดตัวที่ใช้บ่อยไว้คุยเร็วได้ แบบหน้า Browse shared Bots ของ Grok รายชื่อนี้ดึงจากสิทธิ์ (ADR 0034) ไม่ใช่รายการที่ Owner จัดให้ และการรับส่งคำสั่งยังผ่าน Controller ของตัวเองที่เซ็นด้วยกุญแจตัวเอง (ADR 0006) ส่วนความลับของ Agent ยังอยู่ใน supervisor ตาม ADR 0039 ไม่ได้ติดไปกับลิงก์

## Considered Options

- **Owner กดให้สิทธิ์ทีละคนเหมือนเดิม ไม่มีลิงก์**: ปลอดภัยสุด เห็นทุกคนก่อนให้ แต่ช้าและ Owner ต้องอยู่ตลอด
- **ลิงก์แบบใช้ได้ตลอด ไม่มีหมดอายุ**: แชร์ครั้งเดียวจบ แต่ลิงก์หลุดแล้วหลุดเลย ต้องจำไปยกเลิกเอง
- **ลิงก์พาเข้า Workspace ก่อน แล้วค่อยขอ Use แยก**: ได้ตรวจคนก่อนให้สิทธิ์ แต่เสียจังหวะ และ Owner ต้องมากดอีกรอบอยู่ดี
- **เปิดลิงก์แล้วใช้ได้เลยโดยไม่สร้างกุญแจ**: ง่ายสุด แต่ไม่มีตัวตน (ADR 0013) ไม่รู้ว่างานของใคร และไม่มีลายเซ็น (ADR 0006)
- **ไม่มีหน้า Agent ที่แชร์กับฉัน ให้จำชื่อ Agent เอา**: ไม่ต้องสร้างหน้าใหม่ แต่คนที่มี Use หลายตัวหาไม่เจอ และไม่รู้ว่าตัวไหนปักหมุดคุยบ่อยได้

## Consequences

- Member ที่มี Manage ออกกุญแจแชร์ได้จากในแอป ตั้งได้ว่าใช้ครั้งเดียวหรือหลายครั้ง หมดอายุตามค่าเริ่มต้น 24 ชั่วโมง ยกเลิกเมื่อไรก็ได้
- คนเปิดลิงก์ได้สร้างกุญแจของตัวเอง (ADR 0013) ได้เป็น Member และได้ Use บน Agent ตัวนั้นในขั้นตอนเดียว ไม่ต้องรอ Owner
- ลิงก์หลุดเท่ากับใครก็ได้ Use จึงต้องมีหมดอายุสั้น ยกเลิกได้ และหน้ารายการลิงก์ที่ Owner เห็นว่าใครออกกุญแจอะไร ใครใช้แล้วบ้าง
- ลิงก์ที่หมดอายุหรือถูกยกเลิกเปิดไม่ได้ ส่วนคนที่ได้สิทธิ์ไปแล้วยังอยู่ Owner ต้องถอน Use แยก (ADR 0031)
- มีหน้า "Agent ที่แชร์กับฉัน" รวม Agent ที่ตัวเองมี Use (ADR 0034) ปักหมุดตัวที่ใช้บ่อยได้ แบบ Browse shared Bots ของ Grok
- งบ token ยังใช้เพดานของ Agent (ADR 0043) ค่าใช้จ่ายตกที่ key ของคนสั่งแต่ละคน
