# Memory คือ MEMORY.md ที่มีเพดานและตรึงไว้ตอนเริ่ม Task บวกกับการค้น Task เก่าด้วย full-text

ก่อนหน้านี้ Agent จำข้าม Task ได้ทางเดียว คือจดไฟล์ไว้ใน Workdir เอง แต่ไม่มีอะไรรับประกันว่าจะกลับมาอ่าน ADR 0027 ก็เขียนไว้ว่า "ถ้าลืม รอบถัดไปจะแจ้งเรื่องเดิมซ้ำ" Memory จึงเป็นไฟล์ `MEMORY.md` ที่ root ของ Workdir ซึ่ง Runtime ใส่เข้า prompt ตอนเริ่มทุก Task แล้วตรึงไว้ทั้ง Task Agent แก้ไฟล์นี้ได้ด้วย tool ไฟล์ปกติ แต่สิ่งที่แก้กลาง Task จะเห็นผลใน Task ถัดไป แบบเดียวกับ Hermes ทำให้ prompt cache ไม่เสีย ไฟล์มีเพดาน 4,000 ตัวอักษร นับเป็นตัวอักษรเพราะ Runtime นับได้เองโดยไม่ต้องมี tokenizer ของแต่ละ Provider Agent จึงต้องเลือกจดเฉพาะสิ่งที่ทุก Task ต้องรู้ เช่น ข้อตกลง ความชอบของคน และเรื่องที่แจ้งไปแล้ว ถ้าเกินเพดาน Runtime ใส่ให้แค่ส่วนต้นแล้วบอก Agent ให้ย่อ

เรื่องที่ไม่ต้องรู้ทุกครั้ง Agent ค้นเอาจาก Task เก่าของตัวเองด้วย tool ค้นแบบ full-text ด้วย FTS5 ของ bun:sqlite บน `tasks.db` (ADR 0018) ซึ่งไม่ต้องใช้ embedding หรือ Provider เพิ่ม ค้นได้เฉพาะ Task ของ Agent ตัวเอง ซึ่งตรงกับที่ Use เห็นทุก Task ของ Agent อยู่แล้ว (ADR 0031) ส่วนความรู้ที่หลาย Agent ใช้ร่วมกันอยู่ใน Library (ADR 0037) และคำสั่งของ Agent กับ Skill เป็นค่าที่ Member เซ็น Agent แก้เองไม่ได้ (ADR 0038) เส้นแบ่งจึงชัด สิ่งที่ Agent เขียนเองได้คือ Memory, Workdir และ Library ที่ตัวเองเป็นคนเขียน ส่วนสิ่งที่ Member เซ็นคือคำสั่ง Skill, Allowlist และ Egress

## Considered Options

- **ที่เก็บแยกที่ค้นด้วย embedding แบบ Mem0 หรือ Zep**: จำได้มากโดยไม่ต้องใส่ทั้งหมดเข้า prompt แต่ต้องมี Provider ของ embedding กับ index เพิ่ม ขัดกับ Runtime ที่เป็น binary ไฟล์เดียวแบบ BYOK และ Member ตรวจได้ยากกว่าไฟล์เดียว ส่วน benchmark ที่มีส่วนใหญ่เป็นตัวเลขที่เจ้าของระบบวัดเองและขัดกัน
- **memory tool ของ Anthropic**: model ถูกฝึกให้ใช้ แต่ซ้ำกับ tool ไฟล์ที่มีอยู่ และเป็นของเฉพาะ Anthropic ซึ่งขัดกับ ADR 0004
- **ไม่ใส่ให้อัตโนมัติ ให้ Agent ไปอ่านไฟล์บันทึกเอง**: ถ้าลืมอ่าน ก็เท่ากับไม่มีความจำ
- **มีแค่ `MEMORY.md` ไม่มีการค้น Task เก่า**: งานน้อยกว่า แต่ Agent จะพยายามจดทุกอย่างลง `MEMORY.md` จนชนเพดาน

## Consequences

- ระหว่าง Turn ที่อยู่ใน Worktree ของ Project Workdir รวมถึง `MEMORY.md` อ่านได้อย่างเดียว Agent จึงจด Memory ได้เฉพาะตอนทำงานที่ไม่ได้อยู่ใน worktree (ADR 0047)
- Memory โดนวางยาได้ ถ้าหน้าเว็บหรือคนในแชตหลอกให้ Agent จดคำสั่งไว้ คำสั่งนั้นจะติดไปทุก Task รวมถึงของ Member คนอื่น Allowlist กันไม่ได้เพราะการแก้ไฟล์ไม่ผ่าน Allowlist (ADR 0030) ที่ช่วยได้คือการแก้ไฟล์นี้แสดงใน Task และแอปมีหน้าให้อ่าน `MEMORY.md` ได้
- การจัดระเบียบความจำ เช่นย่อบันทึกรายวันลง `MEMORY.md` ทำด้วย Schedule (ADR 0027) แทน sleep-time agent ของ Letta หรือ heartbeat ของ OpenClaw
- เพดาน 4,000 ตัวอักษรตั้งเผื่อภาษาไทย ซึ่งใช้ตัวอักษรมากกว่าภาษาอังกฤษเพื่อพูดเรื่องเดียวกัน และยังตั้งต่อ Agent ไม่ได้ ถ้ามีคนต้องการค่อยเพิ่ม
- ถ้าวันหลังต้องการค้นตามความหมาย ค่อยเพิ่มเป็น tool หรือ Connector แบบ additive
