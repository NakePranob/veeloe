# Agent ผูกกับ Machine เดียว

Agent แต่ละตัวอยู่บน Machine เดียวตลอด และแตะได้แค่ไฟล์ สิทธิ์ และ tool ของเครื่องนั้น ถ้างานต้องทำบนเครื่องอื่น ต้องให้ Agent ที่อยู่บนเครื่องนั้นทำ ตอนนี้ Team อยู่บนเครื่องเดียว (ADR 0026) งานจึงไม่ข้ามเครื่อง Member สั่ง Agent หรือ Team บนแต่ละเครื่องเอง วันที่มีทีมข้ามเครื่อง งานจะข้ามเครื่องได้ผ่าน Delegation เท่านั้น เราไม่เลือกแบบ Agent ลอยตัวที่ระบบหาเครื่องว่างไปรันให้ เพราะแบบนั้นต้องมี scheduler และต้องย้าย context กับไฟล์ข้ามเครื่อง แบบผูกเครื่องทำให้ตอบได้ชัดว่า Agent ตัวไหนแตะอะไรได้บ้าง ซึ่งสำคัญมากเมื่อมันรันคำสั่งบนเครื่องของลูกค้า
