# งานตอนว่างใช้วิธี agent เสนอคนเซ็นครั้งเดียว และตื่นเมื่อเงียบครบเวลาที่กำหนด

งานตอนว่างมีคำถามตั้งต้นว่า agent จะรู้ได้ไงว่าควรทำอะไรตอนไม่มีใครสั่ง เราแยกเป็นสองเรื่อง คือ "รู้เอง" กับ "ตื่นมาทำ" และตัดสินทิศทั้งสองเรื่องในฉบับนี้ กฎกันงานพื้นหลังแย่งงบงานคนตัดสินแล้วว่าใช้ทางกันขั้นต่ำให้งานคนตาม ADR 0043 (ค่าเริ่มต้น 30%) วิธี preempt ตัดสินแล้ว (เจ้าของ 2026-11-01): ชิ้นที่เสร็จแล้วเก็บไว้ ชิ้นที่โดนขัดจังหวะทำใหม่ทั้งชิ้น งานแต่ละชิ้นต้องทำซ้ำได้อย่างปลอดภัย

**เรื่องรู้เอง — agent เสนอได้ แต่ทำต้องมีลายเซ็น:** มีสามระดับ ระดับบอกทุกอย่าง (Member เขียนลิสต์ตายตัว) ปลอดภัยแต่ทื่อ ระดับรู้เองทำเองแบบ Meta Muse (เห็นอะไรก็ทำเลยไม่ถาม) ขัดกับหลักเซ็นล่วงหน้าใน ADR 0006 เพราะไม่มี Member อยู่หลังงาน เราเลือกระดับกลาง คือ agent สังเกตระหว่างทำงานปกติแล้วเสนอว่าเรื่องไหนควรเข้าลิสต์ตอนว่าง Member อ่านร่างเต็มแล้วเซ็นครั้งเดียว หลังจากนั้น agent ทำตามลิสต์ที่เซ็นไว้ได้เอง ลิสต์ระบุลำดับได้สองแบบ คือ Member จัดลำดับตายตัว หรือ Member เซ็นกฎการเลือก (เช่น เอาอันค้างนานสุดก่อน) แล้ว agent เลือกตามกฎนั้น

**เรื่องตื่นมาทำ — เฝ้าสภาพตัวเอง:** ต่างจากตามเวลาที่เฝ้านาฬิกา (ADR 0027) กับ event ที่เฝ้าข้างนอก (ADR 0055) งานตอนว่างเฝ้าสภาพ Runtime เอง ซึ่งรู้อยู่แล้วว่ามี Turn ค้างมั้ย คิวว่างมั้ย ข้อความสุดท้ายมากี่นาทีแล้ว เงื่อนไขตื่นคือสามข้อพร้อมกัน คือไม่มี Turn กำลังทำ คิวว่าง และเงียบมาเกินเวลาที่กำหนด (ตัวเลขอยู่ในนโยบายที่เซ็น เช่น 15 นาที) ครบก็เปิด Turn หยิบงานชิ้นถัดไปในลิสต์มาทำ เสร็จชิ้นหนึ่งเช็กใหม่ว่ายังว่าง งบเหลือ และมีงานเหลือหรือไม่ วนจนกว่าจะหมดหรืองบหมด

กันพังสองข้อ ข้อความ Member มากเมื่อไหร่งานพื้นหลังหลบทันที (ท่าเดียวกับที่ Hermes ให้ข้อความใหม่ interrupt งานได้) เครื่องปิดอยู่ไม่ต้องชดเชยย้อนหลัง ตื่นมาก็เช็กสภาพปัจจุบันอย่างเดียว และงานชิ้นไหนต้องขอ Approval ให้จดไว้ก่อน ไม่ถามตอนนั้นเพราะไม่มีคนอยู่

## Considered Options

- **Member บอกทุกอย่าง ไม่มี agent เสนอ**: ปลอดภัยสุด แต่ลิสต์จะทื่อและเก่าเร็ว Member ต้องคอยมาเติมเอง
- **agent รู้เองทำเอง ไม่ต้องเซ็น**: ฉลาดสุดแบบ Meta Muse แต่ไม่มี Member รับผิดชอบงาน ขัดกับหลักเซ็นล่วงหน้า (ADR 0006) และแยกไม่ออกว่าใครก่อเรื่องเมื่องบหมด (ADR 0043)
- **ตื่นตามเวลาตายตัวแทนเงื่อนไขเงียบ**: ง่ายกว่า แต่จะชนกับงานคน (ตื่นมาทำตอนคนกำลังพิมพ์) และไม่ใช่ว่างจริง เป็น Schedule แบบหนึ่ง (ADR 0027) ไม่ใช่งานตอนว่าง

## Consequences

- นโยบายงานตอนว่างอยู่ในลิสต์ที่ Member เซ็นเช่นเดียวกับของผูก event (ADR 0055) สร้างได้โดย Member ทุกคนที่มี Use (เจ้าของตัดสิน 2026-11-01)
- กฎกันงานพื้นหลังแย่งงบงานคนตัดสินแล้วว่าใช้ทางกันขั้นต่ำให้งานคนตาม ADR 0043 วิธี preempt ตัดสินแล้วตามย่อหน้าแรก เหลือแค่รายละเอียดกลไกก่อนสร้างจริง
- ขอบเขตใน ADR 0027 อัปเดตตามทิศนี้ ส่วนงาน event ในเครื่องยังไม่ได้เลือกทิศ
