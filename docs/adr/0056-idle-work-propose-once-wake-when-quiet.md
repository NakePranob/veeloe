# Idle Work ใช้วิธี Agent เสนอแล้ว Member เซ็น ตื่นเมื่อเงียบครบเวลา และไม่ขัดงานกลางคัน

Agent จะรู้ได้ยังไงว่าควรทำอะไรตอนไม่มีใครสั่ง เราแยกเป็นสองเรื่อง คือรู้เองกับตื่นมาทำ

**รู้เอง:** Member เขียนลิสต์เองทั้งหมดนั้นปลอดภัยแต่ลิสต์จะเก่าเร็ว ส่วนการให้ Agent เห็นอะไรก็ทำเลยแบบ Meta Muse ขัดกับหลักเซ็นล่วงหน้าใน ADR 0006 เพราะไม่มี Member อยู่หลังงาน เราเลือกตรงกลาง คือ Agent เสนอว่าเรื่องไหนควรเข้าลิสต์ Member อ่านร่างเต็มแล้วเซ็นครั้งเดียว หลังจากนั้น Agent ทำตามลิสต์ที่เซ็นได้เอง ลิสต์ระบุลำดับได้สองแบบ คือจัดลำดับตายตัว หรือเซ็นกฎการเลือก เช่น เอาอันค้างนานสุดก่อน Member ที่มี Use สร้างลิสต์ได้ และงานทำในนามของคนเซ็น

**ตื่นมาทำ:** เงื่อนไขตื่นคือไม่มี Turn กำลังทำ คิวว่าง และเงียบมาเกินเวลาที่ตั้งในลิสต์ เช่น 15 นาที ครบแล้วเปิด Task หยิบงานชิ้นถัดไปมาทำ เสร็จแล้วเช็กใหม่ว่ายังว่าง ยังไม่ถึงเพดาน และมีงานเหลือหรือไม่ เครื่องที่ปิดอยู่ไม่ต้องชดเชยย้อนหลัง

ข้อความที่เข้ามาระหว่าง Idle Work ต่อคิวตามปกติ ไม่ขัดงานกลางคัน (เจ้าของตัดสิน 2026-11-01 แทนการตัดสินเรื่อง preempt ก่อนหน้านี้) ถ้าขัดทันที Stop ไม่ย้อนไฟล์ (ADR 0017) คนจะเจอ repo ที่ `git rebase` ค้างครึ่งทาง งานเดิมต้องเริ่มใหม่บนไฟล์ที่เละ และคนที่พิมพ์เป็นระยะจะทำให้งานเริ่มใหม่ซ้ำไม่จบ กฎว่างานต้องทำซ้ำได้อย่างปลอดภัยก็ไม่มีอะไรบังคับ และทำไม่ได้กับงานอย่างการส่งอีเมล งานหนึ่งชิ้นจึงมีเพดานเวลา ค่าเริ่มต้น 15 นาที ถึงเพดานแล้วจบเหมือนโดน Stop และถูกทำเครื่องหมายว่าไม่เสร็จ ระหว่างรอ คนเลือกถามด้วย Ask หรือกด Stop เองได้

Idle Work กับ Watch (ADR 0057) ใช้ token รวมกันได้ไม่เกินเพดานต่อวันของ Agent ซึ่งคนที่มี Manage ตั้ง ค่าเริ่มต้น 30% ของ Budget (ADR 0043) งานที่ไม่มีคนเฝ้าจึงเริ่มจากเพดานต่ำ และยังเหลือ Budget ให้งานคนอย่างน้อย 70%

งานชิ้นไหนต้องขอ Approval ให้จดไว้และข้ามไปชิ้นถัดไป ไม่ถือ Agent รอ เพราะตอนนั้นไม่มีคนอยู่ และงานที่จดไว้จะแจ้งคนเซ็น

## Considered Options

- **Member บอกทุกอย่าง ไม่มี Agent เสนอ**: ปลอดภัยสุด แต่ลิสต์จะทื่อและเก่าเร็ว
- **Agent รู้เองทำเอง ไม่ต้องเซ็น**: ฉลาดสุด แต่ไม่มี Member รับผิดชอบงาน ขัดกับ ADR 0006
- **ตื่นตามเวลาตายตัว**: ง่ายกว่า แต่จะชนกับงานคน และเป็นแค่ Schedule (ADR 0027)
- **ขัดงานทันทีเมื่อคนพิมพ์**: คนได้คำตอบเร็วสุด แต่ไฟล์ค้างครึ่งทางและงานเริ่มใหม่ซ้ำๆ
- **แยก worktree ให้ Idle Work**: คนใช้ Workdir ได้ทันทีและงานไม่ชนกัน แต่ใช้ได้แค่กับ git และต้องรอ worker ต่อ Turn (ADR 0047) เพิ่มทีหลังได้
- **กันไว้ให้งานคน 30% แทนการจำกัดงานพื้นหลัง 30%**: งานพื้นหลังทำได้มากกว่า แต่ใช้ได้ถึง 7M token ต่อ Agent ต่อวันโดยไม่มีใครสั่ง

## Consequences

- งานด่วนอาจรอได้สูงสุดเท่าเพดานเวลาของงานชิ้นหนึ่ง ถ้ารอไม่ได้ต้องกด Stop เอง ซึ่งไฟล์อาจค้างตามกฎเดิมของ ADR 0017
- ลิสต์ยาวอาจทำไม่จบในวันเดียว แล้วทำต่อในวันถัดไป
- ตัวเลข 15 นาทีและ 30% เป็นการประเมินคร่าวๆ ควรปรับเมื่อมีข้อมูลการใช้จริง
- ลิสต์หยุดทันทีเมื่อกุญแจที่เซ็นมันถูกถอน หรือคนเซ็นไม่เหลือ Grant ที่ Agent ตัวนั้น แบบเดียวกับ Schedule (ADR 0031)
