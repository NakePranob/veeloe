# ย้าย Machine ข้าม Workspace ด้วยการที่ Owner เดิมเซ็นปล่อย แล้วทำ Pairing ใหม่ที่เครื่อง

Machine หนึ่งเครื่องอยู่ได้ Workspace เดียว แต่บางครั้งต้องย้าย เช่น บริษัทแยก Workspace ใหม่แล้วอยากย้ายเซิร์ฟเวอร์ไปพร้อม Agent ที่ตั้งไว้ การย้ายพร้อม Agent ทำให้ Workspace ใหม่เห็นประวัติ Task และไฟล์ขององค์กรเดิม จึงต้องให้ฝั่งเดิมยินยอม และต้องกันไม่ให้ Hub สลับกุญแจของฝั่งใหม่ระหว่างทาง (ADR 0006) เราจึงให้ Owner ของ Workspace เดิมเซ็นปล่อย Machine ไว้ก่อน แล้ว Owner ฝั่งใหม่ทำ Pairing ที่เครื่องตามปกติ ซึ่งแลกกุญแจผ่าน QR บนจอของ Machine Hub จึงไม่เคยเป็นคนส่งกุญแจ ถ้ามี Agent ตัวไหนที่ไม่อยากให้ย้าย Owner เดิมต้องลบตัวนั้นก่อนปล่อย และแอปต้องเตือนให้ชัดว่า Workspace ใหม่จะเห็นทุกอย่างบนเครื่อง

Runtime ที่ได้คำสั่งปล่อยที่เซ็นแล้ว จะเก็บ Agent, Workdir, Team กับ Flow และประวัติ Task ไว้ตอน Pairing ครั้งใหม่ แทนการเริ่มจากศูนย์ กุญแจของ Controller ทุกตัวใน Workspace เดิมถูกตัดออก และ Grant ทั้งหมดหายไปเพราะอ้างถึง Member ของที่เก่า Owner ใหม่จึงมี Manage ที่ทุกตัวตามกฎของ Owner (ADR 0031) แล้วค่อยแจกให้คนอื่น Schedule กับ Channel หยุดทั้งหมด เพราะกุญแจที่เซ็นไว้ไม่ได้รับความไว้ใจแล้ว แต่ token ของ bot ยังอยู่ที่ supervisor จึงผูก Channel ใหม่ได้ทันที ประวัติ Task เดิมแสดงคนสั่งเป็น "Member ของ Workspace เดิม" แบบเดียวกับคนที่ลบบัญชี (ADR 0024) ฝั่ง Hub ย้าย Machine ไปอยู่ใต้ Workspace ใหม่ และตรวจโควตาของฝั่งใหม่ตอน Pairing (ADR 0001) ถ้าไม่มีคำสั่งปล่อย Pairing กับ Workspace ใหม่จะเริ่มจากศูนย์ ส่วนโฟลเดอร์ของ Agent เดิมยังอยู่บนดิสก์แต่ไม่มี Agent ตัวไหนอ่านได้ (ADR 0032) เจ้าของเครื่องเลิกผูกเองบนเครื่องได้เสมอด้วย `veeloe unpair`

## Considered Options

- **ย้ายไม่ได้ ต้องเลิกผูกแล้ว Pairing ใหม่โดยไม่มีอะไรตามไป**: ไม่มีทางที่ข้อมูลจะรั่วข้ามองค์กร และไม่ต้องสร้างอะไรเพิ่ม แต่เสีย Agent, Workdir และประวัติทั้งหมดตอนจัดโครงสร้าง Workspace ใหม่
- **โอนทางไกลผ่าน Hub โดย Owner สองฝั่งเซ็นร่วมกันและเทียบรหัสสั้นแบบ Invitation**: ย้ายเซิร์ฟเวอร์ที่อยู่ไกลได้โดยไม่ต้องไปที่เครื่อง แต่ต้องมีกลไกโอนอีกชุด ในขณะที่ Pairing กับเซิร์ฟเวอร์ทำผ่าน SSH ได้อยู่แล้ว

## Consequences

- คำสั่งปล่อยใช้ได้กับ Pairing ครั้งถัดไปครั้งเดียว ส่วนจะมีเวลาหมดอายุหรือให้ Owner เดิมยกเลิกได้หรือไม่ ยังไม่ได้ตัดสิน ถ้า Hub ถือคำสั่งนี้ไว้ก็ใช้ทำอะไรเองไม่ได้ เพราะ Pairing ต้องทำที่เครื่อง
- ย้ายได้ทั้งเครื่องเท่านั้น ย้ายบาง Agent ไม่ได้
