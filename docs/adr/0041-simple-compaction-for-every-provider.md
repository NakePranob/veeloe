# Task ที่ยาวเกิน context ย่อด้วยบทสรุปก้อนเดียว ทำเองใน harness แบบเดียวกันทุก Provider

Claude รุ่นปัจจุบันผูก thinking block ไว้กับทุกอย่างที่ส่งไปก่อนหน้า ถ้า harness ตัดหรือแก้ข้อความเก่า เช่น ลบผลของ tool เก่า หรือย่อแค่ช่วงต้นแล้วเก็บช่วงท้ายไว้ตามเดิม API จะตอบ 400 สำหรับบัญชีที่สร้างตั้งแต่ 31 สิงหาคม 2026 การย่อที่ทำได้จึงมีแค่ compaction หรือ context editing ฝั่ง Provider ซึ่ง Anthropic ไม่นับเป็นการแก้ประวัติ หรือการย่อทั้งก้อน คือสรุปประวัติทั้งหมดเป็นข้อความเดียว แล้วเริ่มคำขอถัดไปด้วยบทสรุปกับข้อความใหม่ โดยไม่ส่งของเก่าซ้ำเลย คู่มือของ Anthropic บอกว่า Claude ถูกฝึกมากับแบบนี้และได้ผลใกล้เคียงกับวิธีที่ซับซ้อนกว่า เราจึงให้ harness ย่อเองแบบทั้งก้อน และใช้กับทุก Provider (ADR 0004)

harness ย่อเมื่อ token ของ Task ใกล้เพดาน context ของ model เช่น 70% ย่อได้ทั้งก่อนเริ่ม Turn และระหว่าง Turn ที่ยาว แต่ห้ามย่อกลาง tool round คือตอนที่ Agent เรียก tool แล้วยังไม่ได้ผลกลับ prompt ที่ใช้สรุปต้องบอกชัดว่าต้องเก็บอะไร เช่น เป้าหมาย สิ่งที่ทำไปแล้ว ไฟล์ที่แก้ และสิ่งที่ค้าง เพราะหลังย่อ บทสรุปคือทั้งหมดที่ Agent รู้เรื่องงานช่วงก่อน บทสรุปต่อท้าย log เป็น event ใหม่ (ADR 0018) ของเดิมใน log ยังอยู่ครบ Member จึงยังเห็นประวัติเต็มในแอป ส่วนที่ย่อมีแค่สิ่งที่ส่งให้ LLM ส่วนต้นของ prompt ที่มีคำสั่งของ Agent, Memory และรายชื่อ Skill ไม่ถูกย่อ

## Considered Options

- **ใช้ compaction ของ Provider เมื่อมี และใช้ของเราเมื่อไม่มี**: บน Anthropic อาจย่อได้ดีกว่าเล็กน้อย และใช้ context editing ล้างผล tool เก่าได้ แต่ต้องดูแลโค้ดสองทาง ทั้งที่การย่อทั้งก้อนได้ผลใกล้เคียงกัน เพิ่มทีหลังได้ถ้าวัดแล้วคุ้ม
- **ย่อช่วงต้นแล้วเก็บช่วงท้ายไว้ หรือย่อเบื้องหลังแล้วสลับเข้ามาทีหลัง**: Agent เห็นงานล่าสุดละเอียดกว่า แต่ thinking block ของช่วงที่เก็บไว้ใช้ไม่ได้แล้ว ต้องลอกออกหรือให้ API ทิ้งให้ ซึ่งซับซ้อนกว่าและเสีย thinking อยู่ดี
- **ไม่ย่อเลย ให้เริ่ม Task ใหม่เมื่อเต็ม**: ง่ายที่สุดและมี Memory กับการค้น Task เก่าพาความรู้ข้ามไปได้ (ADR 0036) แต่ Turn เดียวที่เรียก tool เยอะอาจเกิน context ตั้งแต่กลาง Turn โดยเฉพาะ model ที่มี context แค่ 128–200K

## Consequences

- การย่อแต่ละครั้งเสีย token ของการสรุป และทำให้ prompt cache เริ่มใหม่
- thinking จากก่อนการย่อไม่ตามมา ถ้าบทสรุปตกหล่นอะไร Agent จะไม่รู้เรื่องนั้นอีก
- ถ้า Provider ไม่ใช่ Claude กติกาเรื่องแก้ประวัติอาจไม่บังคับ แต่ใช้วิธีเดียวกันเพื่อให้มีโค้ดชุดเดียว
