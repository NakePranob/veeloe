# Provider ตั้งที่ Machine, supervisor ถือ key และเป็นทางผ่านของทุกคำขอไป LLM และ Agent เลือก model เดียว

issue #11 ให้ตั้ง Provider ต่อ Agent ซึ่งต้องใส่ key เดียวกันซ้ำทุกตัว ทั้งที่ ADR 0005 ตั้งใจให้ "ใส่ในแอปครั้งเดียว" แล้วเข้ารหัสแยกให้แต่ละ Machine และ harness อยู่ใน worker (ADR 0020) worker จึงต้องถือ key เอง ถ้า key ใช้ร่วมกันหลาย Agent ตัวไหนที่โดนหลอกจนดึง key ออกมาจาก env หรือหน่วยความจำได้ ก็ทำ key รั่วแทนทุกตัว เราจึงให้ Owner ตั้ง Provider ไว้ที่ Machine เครื่องหนึ่งมีได้หลายตัว เช่น แยก key ตามทีมเพื่อแยกบิล key ยังเข้ารหัสแยกให้แต่ละเครื่องแบบ sealed box และแอปมีทางลัดให้ใช้ key เดียวกันกับเครื่องอื่นโดยเข้ารหัสใหม่ให้ทีละเครื่อง supervisor ถือ key และเป็น proxy ของทุกคำขอไป LLM harness ใน worker ตั้ง `baseURL` ของ SDK ไปที่ proxy นี้ แล้ว supervisor ใส่ key ก่อนส่งต่อ Agent จึงไม่เคยเห็น key และ supervisor เห็น token ของทุกคำขอ ซึ่งใช้บังคับ Budget ได้ตรงๆ (ADR 0043)

Agent แต่ละตัวใช้ Provider ตัวเดียวกับ model เดียวจากเครื่องนั้น ซึ่งคนที่มี Manage เป็นคนเลือก รายชื่อ model ให้ Runtime ถาม Provider ด้วย key ที่ถืออยู่ เพราะแต่ละ Provider มี model ไม่เหมือนกัน ถ้าเปลี่ยน model จะมีผลตั้งแต่ Task ถัดไป เพราะการเปลี่ยนกลาง Task ทำให้ prompt cache เริ่มใหม่ และ Claude รุ่นปัจจุบันผูก thinking block ไว้กับ model ที่สร้างมัน ส่วน Effort ยังเลือกได้ทุกข้อความ เพราะเป็นตัวคุมราคาที่ไม่ทำให้ thinking เสีย

## Considered Options

- **ตั้ง Provider ต่อ Agent ตามที่ #11 เขียนไว้**: key ของตัวหนึ่งรั่วแล้วตัวอื่นไม่โดน แต่ต้องใส่ key ซ้ำทุกตัว และ key ยังอยู่ใน worker ที่ Agent มีโอกาสเข้าถึงได้อยู่ดี
- **ให้คนเริ่ม Task เลือก model แล้วใช้ไปตลอด Task**: Agent ตัวเดียวเปลี่ยน model ตามงานได้ แต่คนที่มีแค่ Use จะเลือก model แพงด้วยเงินของคนอื่นได้ ถ้าจะกันต้องมีรายชื่อ model ที่อนุญาตต่อ Agent อีกชั้น
- **เลือก model ได้ทุกข้อความแบบ Effort**: ยืดหยุ่นที่สุด แต่ทุกครั้งที่เปลี่ยน prompt cache เริ่มใหม่และ thinking ของเดิมใช้ต่อไม่ได้

## Consequences

- worker ไม่ต้องออกเน็ตไปหา Provider เอง ช่องทางคุยกับ supervisor เป็นทางเดียวที่คำขอไป LLM วิ่งผ่าน (ADR 0008)
- ถ้า Provider ตัวหนึ่งล่มหรือ key หมดอายุ Agent ทุกตัวบนเครื่องที่ใช้ตัวนั้นหยุดพร้อมกัน แอปต้องบอกว่าเป็นที่ Provider
- อยากใช้ model ถูกกับงานเบา ให้สร้าง Agent อีกตัว ซึ่งได้ Workdir กับ Memory คนละชุด
