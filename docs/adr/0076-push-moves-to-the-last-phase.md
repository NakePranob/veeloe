# push ทั้งหมดย้ายไปอยู่ phase สุดท้าย

Status: accepted

เปลี่ยน ADR 0048: เดิม v0.1 มี push ของ Approval, Turn ที่เสร็จ และ Budget (ADR 0044) ตอนนี้ push ทุกชนิดไปอยู่ v0.6 ซึ่งเป็น phase สุดท้าย

สิ่งที่ v0.1 ต้องพิสูจน์คือสั่ง Agent บนเครื่องตัวเองจากมือถือได้อย่างปลอดภัย และไม่เสียเงินเกินที่คิด push ไม่ได้ช่วยพิสูจน์ข้อไหนเลย Budget หยุด Turn ได้เองอยู่แล้วโดยไม่ต้องมีใครเห็น push และ Approval ที่ไม่มีใครตอบก็แค่รอ ไม่ได้ทำอะไรเกินสิทธิ์ แต่ push เพิ่มงานที่ต้องพึ่งของนอก repo: credential ของ Expo กับ Apple และ Google, QA บน iPhone กับ Android จริง และงานลบแจ้งเตือนเมื่อตอบจากอีกเครื่อง (ADR 0053) ก่อนจบ v0.3 มีแค่เจ้าของระบบใช้ ซึ่งเปิดแอปดู Inbox เองได้

**การตัดสินใจ:**

- **v0.6 push** เป็น phase สุดท้าย ต่อจาก v0.5 Channel ได้รับทุกแถวในตารางของ ADR 0044 รวม push ตอน Turn ค้าง (ADR 0073) ค่าปิด push ของ Member และ silent push ที่ลบแจ้งเตือนบนทุกเครื่อง
- phase ไหนที่ยกขึ้นไปก่อนได้ตาม ADR 0048 (เช่น Channel) ไม่ทำให้ push ย้ายตาม push อยู่ท้ายสุดเสมอ
- โค้ด push ที่สร้างไปแล้วใน change `push-notifications` (Runtime ส่ง Generic Push ตอน Approval รอและ Turn เสร็จ, Controller ขอสิทธิ์แจ้งเตือนและส่ง `push.register`) อยู่ต่อได้ แต่ไม่ใช่เงื่อนไขของการออก v0.1 และไม่ต้องทำส่วนที่เหลือจนกว่าจะถึง v0.6

## Considered Options

- **คง push ไว้ใน v0.1 ตามเดิม**: คนสั่งงานแล้ววางมือถือรู้ตัวตั้งแต่วันแรก แต่ v0.1 ต้องรอ credential และ QA บนเครื่องจริงสองระบบ ทั้งที่ไม่ได้ช่วยพิสูจน์ความปลอดภัยหรือค่าใช้จ่าย
- **ย้ายไปแค่ phase ถัดไป (v0.2)**: v0.2 มี Schedule, Idle Work และ Watch ที่ทำงานโดยไม่มีคนกด จึงเป็นจุดที่ push มีประโยชน์ที่สุด แต่ยังต้องรอ credential และ QA ชุดเดียวกัน และจะดึง push ทุกชนิดในตาราง ADR 0044 ตามมาทีละ phase

## Consequences

- จนถึง v0.6 Owner ต้องเปิดแอปเองเพื่อรู้ว่า Approval รออยู่ Turn เสร็จแล้ว หรือ Budget หมด Turn ที่รอ Approval จะค้างจนกว่าจะเปิดแอป
- Schedule, Idle Work, Watch (v0.2), Mention (v0.4) และ `/claim` (v0.5) มาก่อน push เรื่องที่ ADR 0027, 0046 และ 0058 บอกว่าส่ง push จึงขึ้นแค่ใน Inbox จนถึง v0.6 กฎกัน push ถี่ใน ADR 0046 และ 0058 ใช้เมื่อถึง v0.6
- v0.3 ที่เปิดให้คนอื่นใช้จะยังไม่มี push ถ้าต้องการ push ก่อนเปิดตัว ต้องเปลี่ยน ADR นี้
- user story 53–57 ของ v0.1 และข้อ 2.4 ของ change `live-tool-output` ย้ายไป v0.6
