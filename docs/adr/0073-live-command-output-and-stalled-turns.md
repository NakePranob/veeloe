# output ของคำสั่งแบบสด และ Turn ที่ค้าง

Status: accepted

เพิ่มเติม ADR 0018 (Task log) และ ADR 0023 (ข้อความและ event ที่ไม่รู้จัก)

ก่อนหน้านี้ Owner รู้ผลของคำสั่งก็ต่อเมื่อคำสั่งจบ (`tool.result`) ระหว่างที่ build หรือ test รันนานหลายนาที หน้า Task แสดงแค่วงหมุน และ Turn ที่ Provider ไม่ตอบหรือ worker ค้างก็ดูเหมือนกำลังคิดตามปกติ

**การตัดสินใจ:**

- **`tool.output` เป็นข้อความสด ไม่ใช่ event:**
  - worker ส่งท้ายของ output ของ `bash` ที่กำลังรัน ไม่เกิน 2 KB ไม่เกินหนึ่งครั้งต่อวินาทีต่อคำสั่ง พร้อมจำนวน byte ทั้งหมดและเวลาที่รันไปแล้ว
  - supervisor ส่งต่อถึง Member ที่เริ่ม Task เหมือน event ของ Task (ADR 0034, 0060)
  - ข้อความนี้ไม่ถูกเขียนลง Task log และ Controller เก็บไว้ในหน่วยความจำเท่านั้น
  - `tool.result` ยังเป็นผลเต็มที่ LLM อ่านและที่ถูกเก็บ
- **tool รายงาน output ผ่าน task-local:**
  - `veeloe-plugin-api` มี `with_progress` และ `progress()` ซึ่งเป็น task-local ของ tokio
  - worker ตั้งค่านี้รอบการเรียก `bash` และ bash หยิบค่าไว้ก่อน spawn ตัวอ่าน output
  - `ToolRunner` จึงไม่เปลี่ยน signature และ tool ที่ไม่รายงานก็ไม่ต้องรู้เรื่องนี้
- **Turn ค้างคือเงียบเกินห้านาที:**
  - worker จับเวลาต่อ Turn ที่เปิดอยู่ และนับใหม่ทุกครั้งที่มี event หรือ output
  - เงียบครบ `STALL_AFTER_MS` (5 นาที) แล้วจึงเขียน event `turn.stalled { since }` หนึ่งครั้งต่อช่วงที่เงียบ
  - ช่วงที่ Approval รอคนตอบไม่นับ
  - event ถัดไปของ Turn ทำให้หายค้างเอง ไม่มี event แยก
- **Controller ไม่ตัดสินเอง:** Mood ค้างและสถานะ "Turn ค้าง" มาจาก `turn.stalled` เท่านั้น และ Machine ที่ออฟไลน์ยังแสดงเป็นออฟไลน์

## Considered Options

- **เขียน output เป็น event ใน log:** log ต่อท้ายอย่างเดียวและไม่ลบ คำสั่งสิบนาทีจะเพิ่มหลายร้อย event ที่ซ้ำกับ `tool.result` และทุกเครื่องต้อง sync
- **Controller เดาว่าค้างจากเวลา event ล่าสุด:** มองไม่เห็น output จึงนับ build ที่ยังพิมพ์อยู่ว่าค้าง และแจ้งเตือนตอนแอปปิดไม่ได้
- **จับเวลาที่ supervisor:** เห็น worker ที่ค้างทั้งตัวได้ด้วย แต่ supervisor ไม่รู้ว่า Approval กำลังรอคนอยู่หรือคำสั่งกำลังพิมพ์ output ถ้าไม่ส่งสัญญาณข้ามมา ส่วน worker ที่ค้างทั้งตัว Hub ยังบอกได้ว่า Machine ไม่ตอบ
- **เพิ่มพารามิเตอร์ให้ `ToolRunner::run`:** ชัดกว่า แต่ต้องแก้ทุก runner และ plugin ทั้งหมดเพื่อให้มีแค่ bash ตัวเดียวที่ใช้

## Consequences

- Controller รุ่นเก่าข้ามทั้ง `tool.output` และ `turn.stalled` ไปเอง (ADR 0023)
- push ตอนค้างยังไม่มี มาใน v0.6 พร้อม push ชนิดอื่น (ADR 0076) และจะส่งหนึ่งครั้งต่อ `turn.stalled`
- คำสั่งที่เงียบนานแต่ยังทำงานอยู่ เช่น `sleep` จะถูกนับว่าค้าง ซึ่ง Owner เห็นเวลาที่รันไปแล้ว และตัดสินเองได้ว่าจะหยุดหรือรอต่อ
